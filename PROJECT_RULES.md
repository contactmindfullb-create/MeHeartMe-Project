Me❤️Me — Website Development Rules

Core Principle: Reuse what works. Change only what’s necessary.

1. Less coding, faster changes. Prioritize simple, reusable solutions over creating new systems.
2. Preserve existing functionality. Never remove, replace, or redesign working features without approval.
3. One change at a time. Identify the exact file, explain the modification, and test before proceeding.
4. One source of truth. Shared event information should be maintained in one data file wherever practical.
5. Permanent structure, temporary content. Holidays, events, and seasonal themes must not require rebuilding the website.
6. Protect the game. Changes to the Public Event Board must not interfere with Choose a Path or its missions.
7. Mobile-friendly development. Provide clear, precise GitHub editing instructions suitable for an iPhone.
8. Verify before editing. Review the existing code and preserve the website’s established design and architecture.

Development philosophy: Build once. Reuse often. Change carefully.
